Stack ADT (Last-In, First-Out) for Undo Operations

Whenever a record is updated or deleted in the directory, the C engine creates an UndoAction struct snapshot and calls pushUndo() to push it onto the linked list stack. Clicking "Undo Last Action" invokes popUndo() to restore the prior state with zero data loss.

Binary Search Tree (BST) for Department Organization

Each node in the BST represents an academic department. The nodes are ordered lexicographically by department name (strcmp). An in-order traversal (Left $\to$ Root $\to$ Right) automatically visits departments in sorted alphabetical order, grouping all students per department.

Directed Graph & Kahn's Topological Sort Algorithm

Academic courses and their prerequisites form a Directed Acyclic Graph (DAG). Using Kahn's algorithm with an in-degree array and a queue, the C engine determines a valid semester progression without circular dependency deadlocks.

Request Queue (FIFO) O(1) (Enqueue / Dequeue) O(r) requests
